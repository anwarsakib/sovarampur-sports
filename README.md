# ⚽ শোভারামপুর স্পোর্টস ফ্যামিলি — নিজেদের মাঠের অ্যাপ

আমাদের গ্রামের মাঠের **সম্পূর্ণ বাংলা অ্যাপ** — টাকার হিসাব একেবারে স্বচ্ছ, খেলোয়াড়দের ছবি-নাম সহ তালিকা, টুর্নামেন্ট ম্যানেজমেন্ট, নোটিশ বোর্ড এবং ২–৩ জন অ্যাডমিনের নিয়ন্ত্রণ — সব এক জায়গায়। কোনো সার্ভার, ডোমেইন বা মাসিক খরচ নেই; GitHub থেকেই সম্পূর্ণ চলবে।

## ✨ প্রিমিয়াম ডিজাইন — নতুন যা যা (v3)

- **নিজস্ব লোগো ও আসল ছবি:** গ্রামের মাঝে সবুজ মাঠ + সোনালি লরেল রিংয়ের ইউনিক ব্যাজ-লোগো, সেই সাথে ফুটবল ⚽, ক্রিকেট 🏏, ব্যাডমিন্টন 🏸-এর কার্টুন-স্টাইল আসল ছবি — হোম হিরো, ব্যানার আর স্প্ল্যাশে ঘুরেফিরে দেখা যায় (সব ছবি অ্যাপের ভেতরেই এমবেড করা, ইন্টারনেট ছাড়াও চলে)
- **নোটিফিকেশন সেন্টার:** হেডারের 🔔 বোতাম — নোটিশ, নতুন ম্যাচ, ফলাফল বা চ্যাম্পিয়ন ঘোষণায় লাল ব্যাজ ও মেসেঞ্জারের মতো ঘণ্টা-শব্দ (শব্দ বন্ধ/চালু অ্যাডমিন প্যানেলে)
- **টিভি-স্টাইল ফেস-অফ কার্ড:** দুই দলের **লোগো + ক্যাপ্টেনের মুকুট-ছবি** (মেসি-নেইমার স্টাইল) + খেলোয়াড়দের ছবি + কাউন্টডাউন + রেফারির নাম
- **হিসাব আরও শক্ত:** খাত (ক্যাটাগরি) এডমিন নিজের মতো যোগ/বাদ দিতে পারেন — **মাঠ ভাড়া (বছরে ২,০০০ টাকা)**, বিদ্যুৎ বিল, রেফারি ফি ইত্যাদি খাত আগে থেকেই আছে
- **এডমিন অ্যাক্টিভিটি সবার জন্য খোলা:** এডমিন কী যোগ করল, কী বদলাল, কী মুছল — সময় ও নামসহ হোম পেজেই দেখা যায়; হিসাব নিয়ে গন্ডগোলের কোনো সুযোগ নেই
- **সদস্যের মোবাইল নম্বর (ইংরেজিতে):** প্রোফাইলে 📋 চেপে সরাসরি কপি করা যায়
- **রেফারি ব্যবস্থা:** প্রতি ম্যাচে রেফারি/আম্পায়ারের নাম দিন — ম্যাচ তালিকা ও ফেস-অফ কার্ডে দেখা যাবে
- **স্প্ল্যাশ অ্যানিমেশন + অ্যানিমেটেড ব্যানার + কাউন্টডাউন:** ঘূর্ণায়মান রিং-লোগোর স্বাগতম স্ক্রিন, নিজে থেকে ঘোরা ব্যানার (স্লাইডে আসল ছবি), ম্যাচের দিন-ঘণ্টা-মিনিট-সেকেন্ড কাউন্টডাউন, 🥇🥈🥉 মেডেলসহ "কে কত দিয়েছে"

### 📲 নোটিফিকেশন সম্পর্কে সৎ ব্যাখ্যা

এই অ্যাপ **সম্পূর্ণ ইন্টারনেট-ছাড়া চলে** (GitHub Pages স্ট্যাটিক হোস্টিং)। তাই মেসেঞ্জারের মতো "সবার ফোনে একসাথে পুশ-নোটিফিকেশন ভেসে ওঠা" পাঠাতে হলে আলাদা সার্ভার (Firebase ইত্যাদি) লাগে। এই অ্যাপে যা আছে: অ্যাডমিন কিছু যোগ করলে **প্রতিটি ফোনের 🔔-এ লাল ব্যাজ, ঘণ্টা-শব্দ ও পূর্ণ নোটিফিকেশন তালিকা** — সদস্যরা অ্যাপ খুললেই নতুন সব পেয়ে যাবেন। "কয়জন অ্যাপ ব্যবহার করছে" — প্রতিটি ফোনের ব্যবহারের তথ্য (প্রথম খোলা + কতবার খোলা) অ্যাডমিন প্যানেলে দেখা যায়; সব ফোনের তালিকা এক জায়গায় চাইলে ভবিষ্যতে সার্ভার-ভিত্তিক আপগ্রেড দরকার হবে।

## 📱 আসল Android অ্যাপ (APK) বানান — ৫ মিনিটের কাজ

সবার মোবাইলে **Play Store-এর মতো ইনস্টল করা অ্যাপ** — নিজের আইকন, নিজের নাম, ইন্টারনেট ছাড়াই চলে:

1. রিপোটি GitHub-এ push করুন (ওয়েবসাইটের মতোই)।
2. রিপোর উপরে **Actions** ট্যাবে যান
3. বাম পাশে **"অ্যাপ বিল্ড (APK)"** লিস্ট থেকে বাছুন
4. ডান পাশে **"Run workflow"** বাটন → ভার্সন (যেমন `3.0`) দিয়ে **Run workflow** চাপুন
5. ২–৩ মিনিট পর বিল্ড শেষ। সেই রানে ঢুকে নিচের **Artifacts** অংশ থেকে **Shobarampur-Sports-Family-APK** ডাউনলোড করুন — ভেতরে APK ফাইল!

**ইনস্টল করা (সবার জন্য):** APK ফাইলটা WhatsApp/শেয়ারআইটে সবাইকে পাঠিয়ে দিন। ফোনে খুলতেই ইনস্টল চাইবে → **"Unknown sources / অজানা উৎস অনুমোদন"** দিন → Install। ব্যস — হোম স্ক্রিনে ক্লাবের লোগোসহ অ্যাপ বসে যাবে!

**আপডেট:** পরে কিছু বদলালে আবার Run workflow → নতুন APK → পুরনোটার উপর ইনস্টল করলেই হবে — হিসাবের ডেটা ফোনেই থেকে যাবে। (APK-র ভেতরের অ্যাপ সম্পূর্ণ অফলাইন — নোটিশ দেখতে অ্যাপ খুললেই হবে; সবার ফোনে পুশ-নোটিফিকেশন ভেসে ওঠাতে চাইলে `FIREBASE_SETUP.md` দেখুন।)

> 🔐 APK সাইন করা আছে রিপোর ভেতরের কিস্টোর দিয়ে (`android/keystore/release.keystore`) — একই কিস্টোর থাকায় প্রতিবারের আপডেট পুরনো অ্যাপের উপর বসে। গ্রামের ক্লাবের জন্য এটাই সবচেয়ে সহজ ব্যবস্থা; Play Store-এ দিতে চাইলে নিজের কিস্টোর বসিয়ে নিবেন।

## 🚀 ধাপ ১: GitHub-এ তুলে Pages চালু করুন

আপনি আগে অনেক অ্যাপ বানিয়েছেন, তাই এটা আপনার কাছে সহজই হবে:

1. GitHub-এ একটা **নতুন রিপোজিটরি** খুলুন (যেমন: `sobarampur-sports`)।
2. এই ফোল্ডারের **সব ফাইল** (`.github` ও `android` ফোল্ডারসহ) রিপোর `main` ব্রাঞ্চে push করুন।
3. রিপোর **Settings → Pages → Build and deployment → Source: GitHub Actions** বাছুন।
4. ব্যস! প্রতিবার push করলে `deploy-pages.yml` নিজে থেকেই বিল্ড করে সাইট বসিয়ে দেবে।
   ঠিকানা হবে: `https://আপনার-ইউজারনেম.github.io/sobarampur-sports/`
5. **Actions** ট্যাবে গিয়ে বিল্ড সবুজ (✓) হয়েছে কিনা দেখে নিন।

> 💡 ওয়েবসাইটটা এখন **ব্যাকআপ-ভার্সন** হিসেবে থাক — মূল ব্যবহার হবে APK অ্যাপে। দুটোতেই একই অ্যাপ, একই ডিজাইন।

> 📱 গ্রামের যে কেউ এই লিংকটি Chrome-এ খুলে **মেনু (⋮) → "Add to Home screen"** দিলেই অ্যাপের আইকন তৈরি হবে — ইন্টারনেট ছাড়াও চলবে।

## 🛡️ ধাপ ২: প্রথমবার খুললে — অ্যাডমিন তৈরি

অ্যাপ প্রথমবার খুললে নিজে থেকেই **"প্রথম অ্যাডমিন তৈরি করুন"** স্ক্রিন আসবে:

- আপনার নাম ও পদবি (মুখ্য অ্যাডমিন / সহ-অ্যাডমিন / হিসাবরক্ষক) লিখুন
- **৪–৬ সংখ্যার পিন** দিন (সহজ পিন যেমন 1234 রাখবেন না)
- "অ্যাডমিন তৈরি করুন" চাপুন — শেষ!

**আরও ২ জন অ্যাডমিন যোগ করতে:** লগইন অবস্থায় ⚙️ বোতাম → অ্যাডমিন প্যানেল → **+ অ্যাডমিন যোগ** → নাম, পদবি, পিন দিন। পিনটি তাঁকে মুখে জানিয়ে দিন, লিখে পাঠাবেন না।

তিনজন অ্যাডমিনের **সবার সমান অধিকার** — যে কেউ হিসাব লিখতে, সদস্য যোগ করতে, টুর্নামেন্ট চালাতে পারবেন। কে কী লিখল, প্রতিটি এন্ট্রিতে তাঁর নাম জমা থাকে।

## 💰 ধাপ ৩: টাকার হিসাব (স্বচ্ছতার মূল জায়গা)

**যে কেউ** (লগইন ছাড়াই) হিসাব দেখতে পারবে — এটাই ঝগড়া থামানোর উপায়। শুধু লেখার অধিকার অ্যাডমিনদের।

- **কেউ টাকা দিলে:** হিসাব পাতা → **+ আয় যোগ** → নাম (পুরনো সদস্য লিখলে নিজে থেকে আসবে), টাকা, খাত (মাঠ ফি / মাসিক চাঁদা / অনুদান / টুর্নামেন্ট ফি), তারিখ
- **খরচ হলে:** হিসাব পাতা → **+ ব্যয় যোগ** → কী খরচ (বিদ্যুৎ বিল, নেট, বল, মাঠ ভাড়া...), টাকা, খাত
- **তিনটি ট্যাব:** 🧾 *লেনদেন* (প্রতিটি এন্ট্রি, কে লিখল তার নামসহ) • 🙋 *কে কত দিয়েছে* (সবার চাঁদার ব্যার-চার্ট) • 📦 *খরচের খাত* (কোন খাতে কত গেল)
- হোম পেজেই **ব্যালেন্স = আয় − ব্যয়** বড় করে দেখা যায়।

ভুল এন্ট্রি হলে মুছে না ফেলে ✏️ দিয়ে **সম্পাদনা** করুন — ইতিহাস পরিষ্কার থাকে।

## 👥 ধাপ ৪: সদস্য ও ছবি

সদস্য পাতা → **+ নতুন** → গোল বৃত্তে চাপ দিয়ে গ্যালারি থেকে **ছবি আপলোড** → নাম, জার্সি নম্বর, মোবাইল, কোন কোন খেলা (⚽ ফুটবল / 🏏 ক্রিকেট / 🏸 ব্যাডমিন্টন) বাছুন। উপরের চিপ দিয়ে খেলা অনুযায়ী ছেঁকে দেখা যায়। ছবি ফোনেই ছোট করে জমা হয়, তাই জায়গা কম লাগে।

## 🏆 ধাপ ৫: টুর্নামেন্ট চালানো

টুর্নামেন্ট পাতা → **+ নতুন** → নাম, খেলা, ধরন:

- **লিগ:** সব দল একে অপরের সাথে খেলবে → *পয়েন্ট তালিকা* ট্যাব নিজে থেকে তৈরি হবে (জয়ে ৩ পয়েন্ট — বদলাতে পারবেন, ড্রে ১)। শীর্ষ দলের পাশে 👑
- **নকআউট:** কোয়ার্টার ফাইনাল → সেমি → ফাইনাল সাজিয়ে ম্যাচ দিন। ড্র হতে পারবে না।

ধাপ: **+ দল যোগ** (ব্যাডমিন্টনে খেলোয়াড়ের নামও চলবে) → **+ ম্যাচ যোগ** (পর্ব, দল, তারিখ) → খেলা শেষে স্কোর লিখুন → বিজয়ী ও পয়েন্ট অটো হিসাব → সব শেষে **🏆 চ্যাম্পিয়ন ঘোষণা** — সবার হোম পেজে ট্রফি দেখা যাবে।

## 📢 ধাপ ৬: নোটিশ

নোটিশ পাতা → **+ নতুন** → শিরোনাম, বিস্তারিত, প্রকৃতি (🔴 জরুরি / 🟠 গুরুত্বপূর্ণ / 🔵 সাধারণ)। ৩ দিনের নোটিশে "নতুন" লাল ব্যাজ দেখা যায়। নতুন আপডেট সবাই হোম পেজেই দেখবে।

## 💾 খুব জরুরি: ব্যাকআপ ও শেয়ার

এই অ্যাপের ডেটা **প্রতিটি ফোনে আলাদা করে** (ফোনের স্টোরেজে) জমা হয় — কোনো সার্ভার নেই। তাই:

1. **যে ফোনে হিসাব লেখা হয়, সেটিকে "মূল হিসাবের ফোন" ধরুন।** সব এন্ট্রি ঐ ফোন থেকে করুন।
2. **মাসে অন্তত একবার:** অ্যাডমিন প্যানেল → **⬇️ ব্যাকআপ / শেয়ার** → ফাইলটি WhatsApp-এ নিজের/অন্য অ্যাডমিনের কাছে পাঠিয়ে রাখুন।
3. অন্য ফোনে হিসাব দেখাতে: ঐ ফোনে অ্যাপ খুলে **⬆️ ব্যাকআপ ইমপোর্ট** → ফাইলটি বাছুন। (সাবধান: ইমপোর্ট করলে ঐ ফোনের পুরনো ডেটা বদলে যায়।)
4. ফোন হারালে/নষ্ট হলে ব্যাকআপ ফাইল থেকে সব ফেরানো যাবে।

> আগামীতে চাইলে সব ফোনে রিয়েল-টাইম এক হিসাব দেখানোর জন্য Firebase-জাতীয় সার্ভার যোগ করা যাবে — তখন এই ব্যাকআপ-শেয়ার ম্যানুয়াল কাজটা লাগবে না।

## 🧪 নমুনা ডেটা

প্রথমবার অ্যাপটা কেমন দেখায় বুঝতে: অ্যাডমিন প্যানেল → **🎉 নমুনা ডেটা লোড করুন** → তারপর সব পাতা ঘুরে দেখুন। শেষে "সব ডেটা মুছে ফেলুন" দিয়ে শূন্য করে আসল হিসাব শুরু করুন।

## 📲 APK বানাতে চাইলে

`index.html` একটাই স্বয়ংসম্পূর্ণ ফাইল — আপনার আগের যেকোনো WebView অ্যাপ-বিল্ড পদ্ধতিতে (যেভাবে অন্য অ্যাপগুলো করেছেন) এটি `assets/index.html` হিসেবে দিলেই হবে। GitHub Pages ব্যবহার করলে APK ছাড়াই সবাই "Add to Home screen" করে অ্যাপের মতো চালাতে পারবে।
